# 像素肉鸽 · 无尽试炼

一个用纯 HTML + Canvas 写的像素横版肉鸽小游戏。**单文件、零依赖、零联网**，扔到任何静态托管上就能跑。

## 玩

打开 <https://你的用户名.github.io/像素肉鸽仓库名/> —— 或者直接双击本地的 `index.html`。

- **手机**：左下 `◀ ▶` 移动，右下 `跳`
- **电脑**：`A` / `D` 或 `←` `→` 移动，`空格` 跳，死了按 `R` 重来

## 规则

- 自动攻击最近的敌人，你只管跑位和跳
- 每升**半级**给一个词条（也就是每级给两个），三选一
- 等级越高，升级越慢；但怪越强、经验越多
- 18 个词条：攻击/攻速/暴击率/暴击伤害/生命/回血/移速/吸血/多重投射/射程/经验加成/拾取/反伤/击退/冰霜/剧毒/护盾/狂暴
- 4 种怪：史莱姆、蝙蝠、骷髅（远程）、壮汉，按波次解锁
- **你会死。** 词条到后期来得慢，怪是指数变强 —— 死了重开，这就是肉鸽

## 本地起服务器（想让同网段的手机也能玩）

```
python 启动.py
```

它会打印一个局域网网址（会尝试打二维码）。第一次运行 Windows 会弹防火墙窗口，**要点允许**。

手机连不上？最稳的办法是：**用手机开热点，电脑连上去**。校园网的无线通常开了 AP 隔离，同一个 WiFi 也互相访问不到。

## 实现

没有一张图片素材，没有音频文件，没有第三方库。所有像素都是用 `ctx.fillRect()` 画出来的，逻辑分辨率 320×180，靠 `image-rendering: pixelated` 拉伸。

世界宽 900，镜头跟随，背景是两层视差山。
